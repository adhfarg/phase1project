# Pasta Rater

Pasta Rater is a web application that allows users to rate different pasta dishes. Users can upload images of the pasta, provide a rating from 0-10, enter the name of the dish, and leave a comment.

# Features

Upload images of pasta dishes.
Rate pasta dishes on a scale of 0 to 10.
Enter the name of the pasta dish.
Add comments about the dish.
